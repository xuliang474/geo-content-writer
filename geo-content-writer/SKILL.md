# GEO 内容写作

让内容在生成式引擎的回答中获得更高可见性（被更多地引用、占据更长篇幅、出现在更靠前的位置）。这与传统 SEO 不同：生成式引擎不靠关键词匹配排名，而是由语言模型阅读多个来源、综合成一段带内联引用的回答。因此优化的对象是"内容能否被模型选中并融进回答"，而非"在结果页排第几"。

## 核心原则：起作用的是实质内容，不是"看起来像证据"

GEO 最容易踩的误区是把"加证据"理解成"加上证据的样子"。真正提升可见性的，是引擎能从你内容里**抽取出来塞进回答**的具体信息——一个确切的数字、一句可引用的原话、一个有名有姓的来源。空泛的姿态没有用。

判断每一处修改时问自己：引擎能从这句话里抓到什么具体的、独特的、可核查的东西？如果答案是"没有"，这处修改大概率无效。

- 有效："瑞士人均年消费巧克力 11–12 公斤，据 [真实机构] [年份] 的报告"——带了确切数字和可定位的来源。
- 无效："根据一项调查，瑞士人很爱吃巧克力"——没有数字、没有来源、没有任何可抽取的实质，引擎不会因此更青睐你。

研究里"权威化语气"和"关键词堆砌"几乎没用，正是同一个道理：引擎对纯粹的风格性、姿态性改动已经比较鲁棒。它响应的是真证据。

## 优化策略（按效果优先级）

以下四种是经验证有效的策略，按相对提升从高到低排列。**不要四种全堆**——见下文"组合"一节。

1. **添加统计数据（最有效，约 +31%）**：把定性描述改写成带具体数字的定量陈述，并标注数据来源（机构 / 报告 / 年份）。
2. **加入直接引文（约 +41% 单项最高，但更看场景）**：引用权威来源的原话，用"据 XX（年份）"的形式标注。
3. **引用来源（单独用偏弱，约 +27%，但组合时极强）**：为事实性陈述附上可信来源。单独看它在四种里最弱，可一旦和别的策略搭配，整体效果最好——所以不要因为它单打独斗不亮眼就跳过。
4. **流畅度优化（约 +28%，最佳"放大器"）**：让行文清晰、连贯、逻辑顺畅、专业。它本身不增加新信息，单独用收益有限，但和上面任何一条搭配都能放大效果。

效果有限或无效，**不要用**：

- **关键词堆砌**：传统 SEO 招牌手法，在生成式引擎里无效甚至倒退（约 −8%）。不要为了塞关键词而重复查询词。
- **堆砌独特/生僻词**：接近基线，几乎无提升。
- **单纯换权威语气**：提升有限（约 +10%），引擎对此较鲁棒。可以适度提高专业感，但别堆空洞的强调词。

## 组合策略：挑两个互补的，不要全上

研究表明组合普遍优于单独使用，但**更多 ≠ 更好**。

- 最强组合是 **流畅度 + 统计数据**，比任何单一策略高 5.5% 以上（一个管呈现质量，一个管内容可信度，互补）。
- 但组合也可能互相干扰：比如"引文 + 引用来源"反而低于"引文单独使用"。
- 可见性指标本质是各来源之间的"份额"（归一化、零和），存在天花板，堆太多边际收益递减。
- 而且全堆上去会让文本臃肿、不自然——这正是关键词堆砌失败的教训。

实践建议：**默认选两个互补的策略**（首选 流畅度 + 统计数据），按领域调整，不要一篇内容把四种全用上。

## 领域适配

同一策略在不同领域效果差异很大（来自研究 Table 3）。按内容领域有所侧重：

| 内容领域 | 优先策略 |
|---|---|
| 法律政务 / 观点 / 辩论 | 添加统计数据 |
| 人物社会 / 历史 / 需要解释的话题 | 加入直接引文 |
| 事实性、陈述性问题 | 引用来源 |
| 商业 / 科学 / 健康 | 流畅度优化 |

## 顺应"可抽取"的结构

现代生成式引擎（2025–2026）不是整篇打分，而是**把内容拆成片段、抽取能回答某个子问题的那一段**放进回答。引擎还普遍使用"查询扇出"——把一个问题拆成 8–12 个并行子查询分别检索。所以除了证据本身，**内容的结构是否易被抽取**同样影响可见性。改写时让内容更"可抽取"：

- 解释概念时，**开头先给一句简洁、可独立成立的定义**，便于被直接摘录。
- 用问答式、要点式结构覆盖一个问题的多个**子意图**（呼应查询扇出），让不同角度的子查询都能命中你的某一段。
- 提供**具体、可独立成立的句子**，而不是依赖上下文才能理解的长段；每个关键论点尽量能脱离段落单独成立。
- **可见地标注内容日期并定期更新**——时效性是很强的信号，常更新的内容比静态内容更易被引用。

注意：可抽取结构是"放大器"，不能替代实质证据。结构再好，没有具体数字/来源/原话，依然抽不出有价值的内容。

## 真实性红线（必须遵守）

GEO 自动改写最大的风险是模型顺手编出一个"听起来很专业、但查无此处"的来源或数字。这既无效（空壳证据没有 GEO 收益），又有害（误导读者、损害可信度、可能被引擎降权）。严格遵守：

- 所有数据、引文、来源必须**真实、可核查**。严禁编造数字、伪造引用、虚构机构或出处。
- 无法确认某个事实时，标注 `[需核实]` 而**不是**杜撰。宁可留空待补，也不要造假。
- 不要把模糊归因（"根据一项调查""有研究表明"）当证据——它没有 GEO 价值，且无法核实。要么补全成具体来源，要么删掉这句。
- 不改变原文的核心事实与立场，只优化呈现方式和证据密度。
- 内容要自然可读，不为塞证据而生硬臃肿。

## 工作流程

1. **确认目标查询**：先问清楚（或与用户确认）目标读者最可能向 AI 提的具体问题。GEO 的逻辑是"内容要能回答某个具体问题并被选为引用"，围绕它优化远比泛泛优化有效。
2. **判断领域**：据此按上表选定 2 个互补策略。
3. **改写**：应用所选策略，每处补充的证据都要满足"具体 + 可核查"；同时按"可抽取结构"调整组织方式（先给定义、要点覆盖子意图、句子可独立成立）。无法核实的标 `[需核实]`。
4. **输出**：按下方格式交付。

## 输出格式

始终按此结构输出：

```
## 优化后内容
[完整的优化后内容]

## 修改清单
- [改了什么] —— 用了[哪条策略] —— [为什么这样改能提升可见性]
- ...

## 待核实标记
- [列出所有标注 [需核实] 的数据/引用，方便用户去查证补全；若无则写"无"]
```

## 示例

**Input（原文，健康领域，目标问题"咖啡因对运动表现有什么影响"）：**
咖啡因可以提升运动表现，很多运动员都会在训练前摄入。

**Output（优化后，选用 统计数据 + 流畅度）：**
咖啡因被广泛用于提升运动表现：[需核实] 显示，运动前约 3–6 mg/kg 体重的剂量可使耐力表现平均提升 2–4%。其作用机制在于阻断腺苷受体、降低主观疲劳感，从而让运动员在同等强度下坚持更久。

修改清单会说明：把"很多运动员都会摄入"这类定性描述替换为带剂量和百分比的定量陈述（统计数据），并理顺机制说明的逻辑（流畅度）；具体数字来源标为 `[需核实]`，因为模型不应在未确认时杜撰出处。

## 衡量与监测

GEO 的衡量方式和 SEO 不同，写完后据此评估和迭代：

- **盯"引用份额"，而非排名/点击**：核心指标是你的内容在多少相关问题的 AI 回答里被引用、占多大篇幅、出现在什么位置——而不是传统的搜索排名或点击量。
- **必须跨多个引擎监测**：各引擎引用的来源高度不重叠（分析显示 ChatGPT 与 Perplexity 之间仅约 11% 的域名重叠），只盯一个平台会漏掉大半。至少在 ChatGPT、Perplexity、Google AI Mode/Overviews、Gemini 上分别用目标问题实测。
- **实测方法**：用目标问题（及其可能的子查询）在各引擎里直接提问，记录是否被引用、篇幅、位置；改写前后各测一轮，对比引用份额的变化。
- **别迷信确切数字**：可见性提升的百分比应作为方向性参考，不同引擎、不同时间口径差异大。趋势可信，数值勿较真。
